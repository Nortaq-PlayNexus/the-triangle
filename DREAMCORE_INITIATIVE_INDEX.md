# THE TRIANGLE — Dreamcore Initiative Index

**Status:** research and documentation proposal; not an established industry genre, certification, legal opinion, or public launch.

**Snapshot date:** 2026-09-24

This directory is an additive documentation package for investigating whether games substantially derived from their creators' own dreams and nightmares can support a useful, voluntary category. It does not change the game, rewrite Git history, publish anything, contact anyone, spend money, or register any asset or service.

## Current conclusion

The evidence supports a careful distinction between:

1. **Dreamcore** as an already-used internet aesthetic and the title of a released game.
2. **Personal dream-derived interactive works** as a documented creative practice that predates the current proposal.
3. **The proposed provenance-based category** in this project: an interactive work whose creator can document that their own dream experiences materially shaped the work.
4. **Dreamcore Horror** as a proposed horror branch of that provenance-based category, not a currently established formal genre.

The project therefore uses **Dreamcore** as a working term and treats **Dreamcore Horror** as a proposed label. The repository does not establish that the developer invented either term or the underlying practice.

## Non-negotiable guardrails

- “Dreamcore” is not presented as owned, exclusive, or proprietary.
- Existing uses are not treated as adoption of this proposal.
- Tags and search results are discovery aids, not proof of provenance.
- Creators are never required to disclose private or distressing dream details.
- A creator may describe the source at a deliberately abstract level.
- Public classification is voluntary and reversible when consent or evidence changes.
- All legal naming questions are flagged for an Australian IP professional.

## Evidence convention

`EVIDENCE/EVIDENCE_INDEX.md` defines source IDs used across this package. A claim is only as strong as its source. “Not found in this search” is recorded as a limitation, not proof that something does not exist.
