# Press Kit Overview — Draft

**Status:** internal draft; not distributed.

## Story angle

An indie developer is documenting a proposed, evidence-led category for interactive works substantially derived from their creators' own dreams and nightmares. The project grew from the creator's reported personal night-terror experiences while making *THE TRIANGLE*, but the initiative does not claim to have invented Dreamcore or to have created the first dream-based game.

## What is factual today

- *THE TRIANGLE* is a pre-alpha first-person psychological horror prototype.
- Its design includes interconnected nightmares, lucidity, recognition, false awakenings, impossible architecture, and a recurring geometric presence.
- Its source code includes native systems for the bedroom, underground station, Dream Director, anomalies, audio, persistence, and HUD.
- The creator reports a personal night-terror basis in the project brief.
- “Dreamcore” is already used as an internet aesthetic and as a game title.
- Personal dream-derived games have public precedents.
- No independent adoption of this proposal is verified.

## What must not be said

- First, invented, unprecedented, or never-before-seen.
- “Dreamcore Horror is an established genre.”
- “The creator's game proves the category is real.”
- “The game is complete,” “released,” or “playable” without a current verified build.
- Any adoption count based only on tags or search results.
