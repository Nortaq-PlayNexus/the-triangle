## THE TRIANGLE

- **Type:** First-person psychological horror game prototype
- **Engine target:** Unreal Engine 5.8.2
- **Status:** Pre-alpha vertical-slice revamp in progress
- **Premise:** Interconnected nightmares, lucidity, recognition, false awakenings, impossible spaces, and an ambiguous geometric presence
- **Current source environments:** Procedural childhood bedroom and underground station
- **Current source systems:** Lucidity, Recognition, Dream Director, manifestations, motifs, anomalies, false-awakening manager, procedural hum, save/load, HUD, core tests
- **Current blocker:** documented Unreal installation rules-manifest problem; no current build/PIE acceptance claim
- **Assets:** no authored project `.uasset`, `.umap`, mesh, texture, audio, or UI assets found; a generated blockout screenshot exists but is not release evidence

## Proposed terminology

- **Dreamcore:** proposed category for interactive works materially derived from a documented creator-owned dream experience
- **Dreamcore Horror:** proposed horror branch requiring a personal frightening dream/nightmare source and horror intention
- **Status:** not an established industry standard
- **Term collision:** Dreamcore is already used as an internet aesthetic and as a released game title
- **Adoption:** no independent adoption of this proposal verified

## Source wording

The project brief states that THE TRIANGLE is being developed substantially from the creator's own night-terror/nightmare experiences. The current public evidence set records this as creator-reported provenance, not a fully mapped historical source chain.
