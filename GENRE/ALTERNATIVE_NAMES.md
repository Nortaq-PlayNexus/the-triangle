# Alternative Terminology Research

**Status:** candidate list only; no name is selected, cleared, or reserved.  
**Date:** 2026-09-24

The exact word **Dreamcore** has a high collision profile because it is already used as an internet aesthetic and as the title of a released game. The working term can remain useful as descriptive language, but any future badge, directory, title, logo, or trademark campaign needs a current professional search.

The table uses qualitative prevalence because no neutral search-volume study was completed. “Unknown” means that this pass did not establish a reliable count, not that the name is unused. “Potential concern” is a screening flag, not a legal conclusion.

## Screening observations

### Strongest descriptive fallbacks

If clarity is more important than distinctiveness:

- **Dream-Derived Game**
- **Dream-Sourced Game**
- **Nightmare-Derived Horror**
- **Dream-Sourced Interactive**
- **Personal Dream Game**

These are unlikely to be mistaken for the existing Dreamcore aesthetic, but they are also less protectable and less distinctive.

### Potentially distinctive candidates requiring serious screening

- Somnial Game
- Somnial Interactive
- Somnific Game (not recommended without a full linguistic search)
- Nightmare Witness
- Sleep-Sourced Horror
- Dreamweave Interactive
- Oneiric Replay

Distinctiveness is not the same as legal availability. None should be used in a public logo, domain, badge, or registration until an Australian IP professional searches relevant classes and jurisdictions.

## Recommendation for now

1. Keep **Dreamcore** and **Dreamcore Horror** as working research terms because they are the user's current vocabulary.
2. Use a descriptive phrase in public copy until naming research is complete: **“proposed provenance-based Dreamcore category”** or **“creator-derived dream game.”**
3. Do not select an alternative automatically.
4. Revisit this table after creator consultation, linguistic review, and trademark clearance.
5. Record any new candidate with the same fields and an access date.
