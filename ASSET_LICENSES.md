# ASSET LICENSES

Provenance for every external asset used by THE TRIANGLE. Only legally clear assets are permitted; nothing copyrighted is downloaded.

## Current state

**No external assets used.** All current content is:

- Unreal Engine built-in (`/Engine/BasicShapes/*`, engine fonts, `DefaultMaterial`) — covered by the UE EULA.
- Procedural / C++-generated geometry and materials created for this project.
- Original MetaSounds (planned, generated in-editor).

## Policy (from the design doc)

Prefer, in order: UE built-ins → procedural geometry → generated materials → free licensed assets → simple custom meshes. Document every external file here before it enters the project.

_If an asset is added later, record: name, source URL, license, author, date, and where it is used._
