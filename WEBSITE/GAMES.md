# Games Directory — Draft Structure

**No public directory is live.** The following is a transparent starting set for research, not an adoption leaderboard.

## How entries would be shown

Each entry should include:

- title and credited developer;
- release/version date, if verified;
- platform;
- the creator's own wording or a privacy-safe summary;
- which central game elements are materially derived;
- proposed classification and confidence;
- source URL and date observed;
- whether the entry is self-described, third-party-described, or unresolved;
- consent status.

## Initial research examples

- *Clockwork Dreams* — direct creator statement that the game is based on personal dreams and contains 30+ dreams/nightmares.
- *#21: The World* — direct creator statement about a personal dream journal.
- *Dream Diary* — direct creator statement about a real dream.
- *Zemblini: Dream Journal* — direct creator statement about real dreams.
- *My Magical Dream Journal* — direct creator statement about true dreams; horror branch probable.
- *Archive Equinox* — direct creator statement about dreamed locations.
- *My Nightmares Tell Me to Chase My Dreams* — recurring-dream level; partial match.
- *OMORI* — substantial dream/lucid-dream/nightmare input, mixed with other influences.
- *Lucid Falls* — creator says the core idea came from his dreams; extent unresolved.

These examples are precedents for the practice. They have not adopted this project's proposed terminology unless their own public text says so.

## Aesthetic/adjacent examples

- *Dreamcore* — existing game title and liminal-space aesthetic.
- *Dreamcore: Rabbit Hole* — existing use of dreamcore as an aesthetic.
- *Explore Dreams: Dreamcore* — existing use of dreamcore/vaporwave/nostalgicore as style references.
- *Neverending Nightmares* — adjacent autobiographical psychological horror.

## Submission principle

A directory should accept a creator's voluntary, privacy-safe submission. It should not infer membership from a tag, a visual, a fan comment, or an automated recommendation.
