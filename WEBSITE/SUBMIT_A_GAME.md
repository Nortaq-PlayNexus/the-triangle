## Consent choices

- [ ] Public creator name
- [ ] Public studio name only
- [ ] Pseudonym
- [ ] No quotation; paraphrase only
- [ ] No public source description; classification only
- [ ] I can be contacted privately for clarification

## Review promise

The reviewer will apply the published criteria, preserve uncertainty, and not require a complete dream account. A submission is not an endorsement or a legal determination. A creator can request correction or removal.
